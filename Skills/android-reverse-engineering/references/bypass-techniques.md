# Protection Bypass Quick Reference

## Bypass priority order
1. Magisk DenyList (easiest, no code)
2. Objection one-liner (android root disable)
3. Frida combined bypass script (generated by bypass_generator.py)
4. Frida gadget injection (no root needed)
5. Manual smali patching (last resort)

## When nothing works
- Commercial RASP (Promon, DexGuard): multi-layered native checks
- Play Integrity: server-verified, cannot be faked client-side
- Solution: test on a different version, or report that protections exist
